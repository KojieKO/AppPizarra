# Pizarra Pro

Aplicación portable para Windows que organiza archivos PDF y WBH de pizarras, convierte WBH a PDF y permite consultar los documentos junto al horario de clases.

## Descargar 1.0.03

**[Descargar el ZIP portable para Windows x64](https://github.com/KojieKO/AppPizarra/releases/download/v1.0.03/PizarrasPro-1.0.03-portable-win-x64.zip)**

El mismo archivo está a la vista en la raíz del repositorio. Tamaño: 50,5 MB. SHA-256: `850f750932880f49f85919f81d589948f8b4f9935fb4e76e8b6b020a33d5ceea`.

1. Extrae **todo** el ZIP en una carpeta con permiso de escritura.
2. Abre `PizarrasPro.exe`.
3. Elige la carpeta de origen y pulsa **Refrescar**.

Requiere Windows 10 versión 2004 o posterior, o Windows 11, en x64. No necesita instalar .NET ni Python.

## Qué hace

- Organiza y previsualiza archivos PDF y WBH.
- Convierte archivos WBH a PDF.
- Permite consultar el horario, elegir entre tres temas y guardar preferencias.
- Incluye opciones de conexión con OneDrive y Google Drive **aún no validadas con cuentas reales**. La acción actual de subida puede eliminar el original local después de verificar el archivo remoto. No la pruebes con documentos únicos.
