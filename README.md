Este programa es un puente entre las pizarras que la Junta de Extremadura dispuso a partir del curso 23/24 en los diferentes colegios e institutos de la región. Su labor es:

1. Escanear carpetas y archivos PDF
2. Mover los PDF desde las carpetas creadas ad-hoc con el archivo dentro hasta la carpeta raiz (Archivos de Pizarra)
3. Eliminar las carpetas vacías para tener todo mejor ordenado.

Ideas futuras:
1. Poder asignarle horario dentro del rango de horas establecido
2. Mover directamente desde la aplicación a una carpeta destino

Este programa está hecho en Phyton usando vibe coding. Toda revisión humana es bienvenida.
