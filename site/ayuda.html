Ayuda

Instalar y abrir

Descarga el ZIP para Windows x64, extrae todos sus archivos y ejecuta PizarrasPro.exe. Si Windows muestra una advertencia, comprueba que el archivo procede de la publicación oficial.

Archivos y conversión

En Archivos, selecciona la carpeta que contiene tus PDF o WBH y pulsa Refrescar. Puedes previsualizar documentos y convertir WBH a PDF. Conserva siempre una copia de tus archivos antes de convertir o reorganizar un lote.

Horario y preferencias

La pestaña Horario muestra tu planificación. En Opciones puedes ajustar la apariencia y el almacenamiento. Los archivos de preferencias y horario se guardan junto a la aplicación portable; si la llevas en USB, protege también ese soporte.

Conexión

Consulta la página de conexión antes de probar OneDrive o Google Drive. Estas funciones no están validadas con cuentas reales y una subida correcta puede borrar el original local.

Para comunicar un problema, abre una incidencia en GitHub sin adjuntar documentos personales, tokens ni credenciales.
