Privacidad

El portal es informativo y está formado por páginas estáticas. No pide cuentas ni recoge documentos, credenciales o preferencias de Pizarra Pro.

Datos en tu equipo

La aplicación trabaja con las carpetas y documentos que eliges. Los archivos preferencias.json y horario.json se guardan junto a la aplicación portable. Protege la carpeta o memoria USB donde los conserves.

Servicios externos

Si utilizas las funciones de nube actuales, la aplicación se comunica directamente con Microsoft OneDrive o Google Drive para mostrar carpetas y subir archivos. Esas funciones aún no están validadas con cuentas reales; consulta su estado y riesgos. Microsoft, Google y GitHub aplican sus propias condiciones y políticas de privacidad a sus servicios.

Este sitio y GitHub

La web no incorpora formularios, analítica ni cookies propias. Al abrir la web, descargar una versión o seguir enlaces externos, GitHub y los servicios enlazados pueden procesar datos técnicos de acceso conforme a sus políticas. La web y el repositorio no deben contener tokens, secretos ni documentos de usuarios.

Si publicas una incidencia en GitHub, evita incluir datos personales, documentos o credenciales.
