Conexión con la nube

La versión 1.1.01 prepara la información pública. La conexión sencilla para usuarios de distintos centros llegará en tareas posteriores.

Estado actual: las conexiones y subidas con cuentas reales de Microsoft y Google no se han validado. La acción actual de subida puede borrar el PDF local después de verificar el archivo remoto. Guarda una copia independiente; no uses documentos únicos para probar esta función.

OneDrive

La aplicación incluye un inicio de sesión en navegador, selección de carpeta remota y subida básica. Todavía falta configurar y probar el acceso para cuentas personales y educativas de otros centros. Algunas organizaciones pueden impedir el consentimiento por sus políticas.

Google Drive

La conexión actual requiere un archivo de configuración OAuth de escritorio aportado por el usuario. La conexión sin ese archivo y la validación para cuentas externas están previstas para una versión posterior. No subas ese archivo ni credenciales al repositorio.

Qué está previsto

Las próximas versiones abordarán el acceso desde el navegador, la protección local de las sesiones y la conservación del PDF original tras cada subida. La disponibilidad para un centro concreto dependerá también de sus políticas de Microsoft o Google.
